## この変更で、本番に入るもの

| 区分 | 内容 | 本番への操作 |
|---|---|---|
| API（Lambda `message-api-tf`） | コードの入れ替え（自分の名前が空でも保存。`GET /members` が非表示の人を外す。`PUT /members/{memberId}` を追加） | `aws lambda update-function-code` |
| API Gateway | ルート `PUT /members/{memberId}` を1本追加 | `aws apigatewayv2 create-route` |
| 画面（S3・CloudFront） | 新しい画面（自分の名前の入力式、伝言先の並び、社員の管理） | `aws s3 sync`、キャッシュの消去 |
| データ（Members） | 「営業」の行を追加（総務・経理・人事は登録済み） | `aws dynamodb put-item` |

**変わらないもの：** `Messages`・`NuisanceNumbers` の表、Lambda の環境変数、CORS（`PUT` は、10/20 に許可済み）、実行ロール（`AmazonDynamoDBFullAccess` なので、`Members` の更新も可能。10/20 の記録より）。

**順番：API → 画面。** 新しい画面は、古い API では「社員の管理」が動かない。新しい API は、古い画面とも両立する。

表記: コマンドは PowerShell で1つずつ実行する。`<…>` は自分の値に置き換える。プロファイル `shift-prod`、リージョン `ap-northeast-1`。下の ID は、10/20 の記録の値。**変わっていないか、コンソールで確認する**（確認が必要）。

| 値 | 10/20 の記録 |
|---|---|
| API Gateway の API ID | `kn3somrtp6` |
| 統合 ID | `y627lw0`（Lambda を、バージョンなしで指す） |

## 3. 「営業」を追加する

文字化けを避けるため、**先に文字コードを指定する**（この窓の中だけで有効）。

```
$env:AWS_CLI_FILE_ENCODING = "UTF-8"
```

`<ID>` は、既存のグループの付け方（0章で確認）に合わせる。

```
$json = @{ memberId = @{ S = "<ID>" }; memberName = @{ S = "営業" } } | ConvertTo-Json -Compress
$file = "$env:TEMP\member-sales.json"
[IO.File]::WriteAllText($file, $json, (New-Object Text.UTF8Encoding $false))
aws dynamodb put-item --table-name Members --item "file://$file" --profile shift-prod --region ap-northeast-1
```

- [ ] 表の名前が **`Members`**（本番）であること。コンソールで、「営業」が日本語で見える（化けていない）
- [ ] 同じ `memberId` が、すでにないこと（あると、上書きされる）

## 5. リリース後の確認（本番の画面）

本番の画面（`https://d11xxeftrnkpe5.cloudfront.net`）で行う。**本番の「71_伝言メモ」に通知が届くので、本文に【テスト】と書く。** 確認後、テストの伝言は削除する。

| No. | 確認 | 期待 | 結果・確認者・日時 |
|---|---|---|---|
| R01 | 登録フォームを開く | 「自分の名前」が打ち込む欄で「任意」。伝言先の先頭が、総務→経理→人事→営業、そのあとに個人名 | |
| R02 | 自分の名前を空にして、【テスト】の伝言を登録 | 一覧に移る。詳細に「受電者：（未入力）」。「71_伝言メモ」に届き、本文が「受電者: （未入力）」 | |
| R03 | 既存の伝言 | これまでの伝言が、一覧に出る（件数が減っていない） | |
| R04 | 画面の下の「管理」→ 社員の管理 | 小さく薄いリンクで開く。全員が表示中に出る | |
| R05 | 非表示の確認用に、**確認用の人を1人、本番に足す**（下のコマンド）→ その人を「非表示にする」→「表示に戻す」 | 非表示で、伝言先から消える。戻すと復活する | |
| R06 | R05 の確認用の人を、削除する（下のコマンド） | 管理画面から消える | |
| R07 | 迷惑番号の画面（既存の機能） | 一覧が出る・照合できる | |
| R08 | Lambda のログ（CloudWatch、直近1時間） | エラーが出ていない | |

R05 の確認用の人を足す・R06 で消すコマンド（**文字コードの指定が済んだ窓で**）:

```
$json = @{ memberId = @{ S = "release-check-1" }; memberName = @{ S = "【確認用】削除予定" } } | ConvertTo-Json -Compress
$file = "$env:TEMP\member-check.json"
[IO.File]::WriteAllText($file, $json, (New-Object Text.UTF8Encoding $false))
aws dynamodb put-item --table-name Members --item "file://$file" --profile shift-prod --region ap-northeast-1
```

```
aws dynamodb delete-item --table-name Members --key "{\"memberId\":{\"S\":\"release-check-1\"}}" --profile shift-prod --region ap-northeast-1
```

（`--key` の書き方が PowerShell で通らないときは、上と同じ要領で、JSON をファイルにして `file://` で渡す。）
