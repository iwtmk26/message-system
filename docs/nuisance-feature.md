# 迷惑番号チェック機能

電話を受けたらまず番号を検索し、迷惑電話かどうかをすぐ判断できる画面を追加した。
現在は**ブラウザ内の仮データ**で動作する。AWS(DynamoDB + Lambda)での共有保存は今後の予定。

## 目的と業務の流れ

営業・迷惑電話は伝言としてチャットに残るだけで、同じ番号からの着信を見分けられなかった。
番号をリスト化し、電話対応の最初に照合できるようにする。

1. 電話を受ける
2. 保留にして、システムで電話番号を検索する
3. 登録なし → 通常どおり担当者に取り次ぐ、または伝言を登録する
4. 登録あり(迷惑番号) → 画面の表示を見て対応し、今回の着信を記録する

## 画面

| 画面 | パス | できること |
| --- | --- | --- |
| 番号検索 | `/nuisance` | 番号を入力して照合。登録なしは緑、登録ありは赤で表示 |
| 迷惑番号リスト | `/nuisance/list` | 一覧、キーワード絞り込み、登録、編集、削除、着信ログの確認 |

- 登録・編集は全員ができる。
- 「番号検索」ボタンを、登録フォームと伝言一覧のヘッダーに追加した。
- 登録なしの画面から、番号を引き継いで「伝言を登録する」「迷惑番号として登録する」に進める。
- 全角数字、ハイフン、`+81` 付きの番号も同じ番号として扱う。重複登録は防ぐ。

## 現状の制限

- データはブラウザの localStorage(キー `nuisanceNumbers.mock.v1`)に保存される。
- 他の人のPCとは共有されない。初期データは架空の3件。

## 今後の予定

- AWS(DynamoDB + Lambda)に保存し、全員で共有する。残り工数の目安は約9〜10時間。
- 画面側は `frontend/src/nuisance/nuisanceApi.ts` の中身を `fetch` に差し替えるだけで済む作りにしてある。
- AWS側の作業は、会社の許可と自分用のAWS環境の準備が整うまで保留。`terraform apply` は許可が出るまで実行しない。

## 番号の整形(正規化)

保存と照合は、数字だけにそろえてから行う。

```ts
const digits = half.replace(/\D/g, ""); // 数字以外を取り除く
```

全角を半角にし、先頭が `+81` なら `0` に直す処理も `normalizePhone` に含まれる。桁数は 8〜15 桁。
